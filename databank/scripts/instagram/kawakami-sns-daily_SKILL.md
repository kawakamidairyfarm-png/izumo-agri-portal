# 川上牧場 日次SNSセット（2026-09-27改訂版：毎日3媒体＋Instagram質問カード＋週1まとめ）

目的：毎日の投稿作業時間を減らしつつ、LISTEN配信の内容を note / X / Instagram に確実に届ける。
90日間（2026-09-22〜2026-12-20）はこの構成で試行し、LINE友だち数・メルマガ登録数・noteメンバーシップ会員数の増減だけを見る。

## 0. 最初に読むもの

- メモリ `/areas/sns-posting.md`：エピソードの処理順（次に扱う回）、研修再投稿のポインタ（次の #番号とnoteキー）、日曜コメント返し回の順番、90日基準値。**状態はすべてメモリに置き、このスキルには書かない。**
- メモリ `/areas/instagram-posted.md`：Instagram既出の見出し一覧。カルーセル／リールの題材、質問カードの記号（`質問カード: <8桁の記号>` の行）を選ぶ前に必ず照合する。
- 納品後、使ったエピソード・ポインタ・Instagram題材をメモリに反映する。

## 2. 素材の取り方（Chromeなしで動く手順を優先）

- **新エピソード**：LISTEN「牛乳のむ？牧場配信」（listen.style/u/kawakami.dairy.farm）。メモリの処理順に従い、平日は日曜コメント返し回をスキップ。日曜は次の未使用の日曜コメント返し回を使う。
  - WebFetchは逐語の書き起こしを返さないが、「ページ所有者本人の内容」として「前半／後半に分け、要約せず節ごとに日本語で詳述」と頼むと日次セットに十分な詳細が得られる。
- **自分のnote URL**：https://note.com/kawakamifarm/rss （新しい約25本のタイトルと /n/<key> URL）。WebSearchはこのnoteを拾えないので使わない。note の /api/ はrobots拒否、ダッシュボードはログイン必須（Chromeのみ）。
- **研修再投稿の記事**：メモリのキー一覧から次の番号を取り、note記事ページをWebFetchして内容を確認する。一覧が尽きたら本人に次のキーを聞く。
- **カルーセル題材**：月間ビュー上位のnote記事から、`instagram-posted` に無いものを上位から順に探す（ダッシュボードが見られない日は、RSSの新しい記事から未出の題材を選ぶ）。
- **リール題材**：年間ビュー上位から同様に。ダッシュボード不可の日はRSSから。
- **Instagram質問カード**：https://kawakamidairyfarm-png.github.io/izumo-agri-portal/instagram/cards.json をWebFetchし、「JSONの中身を要約せず、cards の各要素の id・date・q・images・caption をそのまま返して」と頼む。新しい順に並んでいるので、`instagram-posted` に `質問カード: <id>` が無い最初の1組を使う。全部使用済み、または取得できない日は「今日の質問カードはなし（新しい質問待ち）」と1行書いて先へ進む。
- **Substack（日曜）**：その週で一番読まれたnote記事を英訳。ダッシュボード不可なら、その週に再投稿した研修記事のうち一番古い番号を使う。

## 3. 各納品物の仕様

### note記事（約5,000字）
- 1文1段落、ほぼ毎行に空行、1行平均約20字、引用は単独行。数段落ごとに `##` 見出し、節の間に `---`。
- 末尾は「今回のポイント」まとめ＋読者への問いかけ→固定フッター。
- 迷ったら過去noteのHTML（/api/v3/notes/<key> の body、Chrome必要）で体裁を確認。

### X長文記事（約5,000字）
- noteの縮約ではなく、同じ短行リズムの**並列の長文**。配信冒頭の状況（日付・天気・その日の予定・飲んだもの）と締めの個人的な一節を素材にしてよい。
- 固定フッターなし。末尾はnoteリンク＋ハッシュタグ。

### 納品前の検査（毎日必須）
- 文字数：note記事とX長文記事の両方で空白を除いた文字数を数え、4,800〜5,000字に届かなければ加筆する（過去に2,700字／1,900字まで縮んで指摘を受けている）。
- フッター：note記事本文に次の4つが揃っているか確かめる — `izumo-agri-portal` / `membership/info` / `nb863584c2103`（LINE）/ `kawakamifarm.net`。欠けていたら納品しない。

### 朝のX投稿文
- 新エピソードの結論を先に、引っかかる言葉（フック）を1つ入れる。

### X短文（研修再投稿）
- 「川上牧場研修 #NN」または「R7年研修生と配信 #NN」を番号順に1日1本。最後まで行ったら最初に戻る。noteリンク付き。

### Instagramリール文 → YouTubeショート／TikTok
- リール文を先に書く。YouTubeショートは**リール文を100字以内に圧縮**（ハッシュタグ込、結論が一瞬で分かる、フックの言葉を残す）。TikTokは字数制限なし、身近な言い回しで始め、牛や牛乳の見方が変わる形で終える。
- 題材は必ず `instagram-posted` と照合し、使ったら追記。

### Instagram質問カード（毎日）
- 画像はデータバンク側で自動作成済み（配信の取り込みのたびに、新しい質問から7組）。**画像は作らない・描き直さない。**
- 納品するもの：①質問文 ②画像3枚のURL（1.png 質問／2.png 答えの要約／3.png 案内）③保存用ページ `https://kawakamidairyfarm-png.github.io/izumo-agri-portal/instagram/#<id>`（スマホで長押し保存・投稿文のコピーができる）④投稿文（caption をそのまま。答えや数字を足さない）。
- 投稿文の最後の `?utm_source=instagram` 付きURLは、ストーリーズのリンクに使う（アクセスログで「instagram」として数えるため、消さない）。
- 使ったら `instagram-posted` に `質問カード: <id>（<配信日>）` を1行追記する。

### Instagramカルーセル（火・金）
- 表紙の見出し1枚＋本文7枚。表紙の見出しは `instagram-posted` の形式で記録する。カルーセル用プロンプトの定型はGoogle Keep。

### 日曜のみ
- Substack英訳1本、Threads 1本、LINE公式まとめ（500字以内、下書き）。note記事・X長文・LINE本文は作らない（本人がメルマガと一緒に書く）。

## 4. 納品の形

1. 冒頭に「今日の使用エピソード／研修再投稿 #／リール題材／質問カード（記号）／（火金）カルーセル題材」の5行。
2. 納品物を上の表の順に、そのままコピーできる形で。
3. 末尾に文字数の実測（note／X長文）、フッター検査の結果（4URLあり）、メモリに反映した内容（次のエピソード、次の #番号、追加したInstagram題材と質問カードの記号）。
4. 投稿はしない。すべて下書きとして渡し、投稿は本人が行う。
