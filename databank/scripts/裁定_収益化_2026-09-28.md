## 見立て（明鏡）
- 柱7（本命逆算）: 月10万円をメンバーシップだけで作ると、仮に月500円なら200人（手数料を引く前）。いまの増え方では遠い。**高単価×少数（伴走・企業相談・協賛）が本命で、メンバーシップは継続・応援の段**。
- 柱2（ファネル）: データバンクは集客・信頼の装置としては育ったが、有料への受け渡し（転換）がほぼ0。穴は「販売」ではなく「教育→販売」の間。メルマガに入った人へ10〜20日かけて価値を届け、そのあとに1つだけオファーを出す形がまだ無い（登録直後メールでメンバーシップを案内しているだけ）。
- 柱6（文化は経済より先）: データバンク本体に壁（有料化・広告）を作らない。「登録なしで読める」が旗であり、LIVEの視聴者との関係そのもの。
- 異見役（イケハヤAI）: 「この2週間、サイトを磨く作業が中心だった。月10万円が目標なら、今日1件、高単価の相談を売りに行くほうが早い。データバンク磨きが売らない言い訳になっていないか」→ **採用**。次の30日はサイトの新機能を止め、売る動きに時間を使う。

## 裁定（効く順）
1. **本命を1つに決めて、データバンクをその営業資料にする。** 候補は「牧場経営者向け伴走（月額）」か「企業向けの現場相談（スポット）」。どちらも既に売った実績がある商品なので、新商品は作らない。/expert と伴走の紹介に「どの回で何を話したか」を証拠として並べる（832回の一次情報が信頼の証拠になる）。
2. **メルマガのステップに「教育→1つのオファー」を足す（飲む人向け）。** 3〜14日目に牛乳の話を届け、14日目前後にメンバーシップを1回だけ案内する。登録直後メールの案内はそのまま。文面の魂は本人、下書きと検品はAI。
3. **DXサミット協賛は、データバンクの数字を協賛の説明資料に使う**（来訪・LINE・メルマガの実数。盛らない）。1件の金額が大きいので、10/1の期限までの動きを優先。
4. 学校向けは収益ではなく文化の段として続ける（出前授業・見学の依頼が来たら個別に）。

## 追記（同日）: 本人から実数
- メンバーシップ 月450円・8人 → 月3,600円（手数料前）
- 伴走 月1万円・1件 → 月10,000円
- スポット相談（ビザスク等） 1件3万円・2件 → 月60,000円（毎月続くとは限らない）
- 目標: 牛乳生産以外の収入を**安定して**増やす（件数が月ごとに揺れるスポットより、毎月入る収入を太らせる）

### 試算
- いまの安定収入 = 3,600 + 10,000 = **月13,600円**。スポットを足すと月73,600円だが、スポットは不定。
- 市場がつけた時間の値段: スポット1件3万円。伴走は月1万円で、スポット1回の3分の1。**伴走が安すぎる可能性が高い**（伴走に月何時間使っているかは未確認）。
- 安定収入を月10万円にする式（手数料前）:
  - 案1 伴走を1万円のまま増やす: 追加9件（計10件）→ 100,000 + 3,600。時間が一番重い。
  - 案2 伴走の新規価格を上げる（既存1件は据え置き）: 新規3万円×3件 → 90,000 + 10,000 + 3,600 = 103,600。
  - 案3 企業向けの月額相談（顧問）を1つ作る: 月3〜5万円×2社 → 60,000〜100,000。スポットの実需（月2件）が根拠。
  - メンバーシップだけ: 100,000 ÷ 450 = 223人。長期の目標としてはあり、30日の本命ではない。
- リスク: ビザスク経由で知り合った依頼者と直接契約することは、規約で制限されている可能性が高い → 案3はビザスクの相手には持ちかけず、/expert・DXサミットの協賛候補・取材先などから探す（規約は本人が確認）。

### 裁定（追記）
- 本命は **案2＋案3**。1件で月2〜5万円入る形を2〜4件つくるのが、搾乳の合間の時間で一番届きやすい。
- 価格は本人が決める。AIは案内文・問い合わせ導線・データバンクの証拠ページまで作る。
- メンバーシップは450円のまま、ステップメールで人数を増やす段（30日の目標は8→12人、勘）。
