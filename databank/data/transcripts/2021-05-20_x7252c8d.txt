## 同い年で非農家出身。2人はどんな道を歩いてきたのか

今回のスペースは、川上さんの音声配信の番外編として開かれました。ゲストは、富山県で酪農家をしている青沼晃さんです。

川上さんがこの回で伝えたかったのは、酪農未経験から酪農家になった青沼さんの体験を通して、これから業界を目指す人に何かを届けることでした。

>> 川上｜酪農未経験で酪農家になった青沼くんの意見をいろいろ聞いてみたいなと思って招待してみました。

話してみると、2人には共通点が多くありました。どちらも非農家出身で酪農家になり、しかも年齢まで同じ。ともに寅年です。

>> 青沼晃｜川上さんもですけど、非農家出身で酪農家になってる。二人で。しかも年齢も同じだと。

青沼さんは愛知県出身で、大学で北陸に進んだのをきっかけに牧場を転々とし、富山県の育成牧場で出会った奥さんと結婚。第三者継承という形で牧場を買い取り、2015年に新規開業しました。今は経産牛45頭、育成牛を合わせると85頭を、フリーバーンという飼い方で育てています。

%% 第三者継承｜血縁関係のない後継者が、離農する農家から牧場や設備、牛群などを引き継いで経営を始める形。親子間の継承と違い、非農家出身者でも農業を始めやすい道として注目されています。

%% フリーバーン｜牛をつながず、敷料を敷いた広い牛舎の中で自由に動けるようにして飼う方法。牛が動きやすい一方で、敷料の管理や糞の処理に工夫が必要になります。

一方の川上さんは、農業大学校を卒業後に鳥取県で酪農ヘルパーになり、結婚を機に婿として島根県の酪農家の3代目になりました。

## つなぎ牛舎をフリーバーンに。青沼さんの型破りな継承

2人はTwitterで以前から交流があり、青沼さんが牛舎を第三者継承する頃からのつながりでした。川上さんが特に面白いと感じたのは、青沼さんがつなぎ飼いの牛舎をフリーバーンに変えた発想です。

>> 川上｜つなぎをフリーバーンにするっていうのがすっごい僕の中でお、この人面白えなって思ったんだけど。

川上さんによると、第三者継承では経営体をそのまま引き継がなければいけないと思い込んでしまう人が多いといいます。そこでフリーバーンに変える発想が出てくること自体が新鮮だった、というわけです。

青沼さんが継いだのは、24頭のつなぎ飼いの牛舎でした。パイプラインは22頭分しかなく、しかも設備は老朽化していました。

>> 青沼晃｜マックス22頭しか働かせれない状況で、3700万の借金を12年で完済するって考えたら結構ハードじゃない。

バーンクリーナーはなく、パイプラインは40年ほど経過。飼槽も昔のタイル張りでボロボロで、改修するだけで2600万ほどかかる状況でした。

さらに、始めた年に子どもが生まれ、奥さんは労働力に数えられない状況。基本一人でやることを考えると、省力化は避けられませんでした。そこで青沼さんは、お金をかけずに省力化する道としてフリーバーンを選びました。

>> 青沼晃｜中古でボロいちっこいホイールローダー買ってきて、頭数をある程度過密にしてでも増やせるっていうことで、フリーバーンを選択した。

つなぎ飼いの仕切りを全部取り払い、細かい起伏は敷料で埋めるだけ。コンクリートを貼って平らにする工事はしていません。堆肥を全部取り出すと、昔の牛舎の形が出てくるといいます。

>> 青沼晃｜フリーバーンの堆肥を全部取り出したら昔の形が出てくるっていう状況。

この方法で、稼働者の整備は200万円ほどで済みました。搾乳設備も、中古のアブレストが出たタイミングで導入。オリオンの担当者がサービス仕事のような形で移設してくれたそうです。

%% アブレスト｜搾乳する牛を横一列に並べて搾る方式のミルキングパーラー。設備がコンパクトで、パイプラインの長さを短くできるため、小規模な牧場でも導入しやすいのが特徴です。

## 「成功例にしたくない」青沼さんの就農はどれだけ特殊だったか

川上さんは、こうした第三者継承の成功例を聞くと、つい難しく感じてしまうと話します。ただ、青沼さんのケースは努力次第で持っていった側面が大きいと見ています。

>> 川上｜青沼くんがすげえんだよ。だってそれって。

これに対し青沼さんは、あまり硬く考えないようにしていたと振り返ります。理想は持ちつつも、牧場を始める段階で全てを叶えることは捨てていた、というのです。

>> 青沼晃｜牧場始める段階なんで、そこでもう全てを叶えるっていうことは捨ててました。とりあえず牧場始めよう。

川上さんは、青沼さんが元々見たであろう24頭のボロボロのつなぎ牛舎を、100人に見せて「やる」と言う人は一人もいないだろうと言います。それでも青沼さんは「できるイメージしかなかった」と手をつけました。

>> 青沼晃｜もうできるイメージしかなくて、手付けた。

2人が就農を急いだ背景には、年齢の制限がありました。青沼さんも川上さんも、就農のリミットを自分の中で設けていたのです。

>> 青沼晃｜俺30までにはやりたいなと。

青沼さんは、借金を返して終わりでは面白くない、次の世代に渡すタイミングでもう一度何かしたい、という長いスパンで物事を考えていました。だからこそ時間がなく、条件を選んでいる余裕もなかったといいます。

当時出てきていた物件は、大半が牛舎が傾いているようなものばかり。そんな中で、まだ牛が7頭いて酪農が続いている場所だったことが、青沼さんにとってはかなり良い条件でした。

>> 青沼晃｜見に行ったその日に即決して。

しかも継承はスムーズどころか、ほぼ引き継ぎなしの「射抜き」でした。おばあちゃんが一人でやっていて、青沼さんが来る日にはもう荷物をまとめ、市営住宅まで送っていったといいます。餌のやり方も教わらないまま始まったのです。

>> 青沼晃｜この牛に何キロ餌やってるとか、そんなんも教えてもらえずに。

おばあちゃん側も追い込まれていました。一緒にやっていたお父さんが施設に入ることになり、半年後には来てくれという話。青沼さんは働きながら、公庫の資金借入や青年就農給付金など、認定新規就農者になる手続きを半年でこなす必要がありました。

>> 川上｜漫画みてえだな、マジ。

こうした経緯から、川上さんは青沼さんを安易な「成功例」として扱いたくないと繰り返します。青沼さんも「よくない」と同意しつつ、その前に何度も失敗を重ねてきたことを明かしました。

>> 青沼晃｜後継者候補で入ったところも失敗したし、その後に、本当にサラ地から牧場を始めるっていうので計画立てて。

## 後継者はいるのに、なぜ経営が傾くのか

川上さんが業界で危機感を持っているのは、後継者がいるはずの牧場でも、うまくいかないとズルズル悪い方向に進んでしまうケースが多いことです。

>> 川上｜うまいとこ行ってないとこはもうズルズル悪い方向にしか進んでないケースがまあいっぱいあって、それを変えたいんだよね、僕は。

川上さんが問題視するのは、経営を親父さんが持っている以上、後継者には経営の責任はないのに、労働力としては責任のある場所をやらされているという矛盾です。もし親父さんが急に倒れたら、後継者は何もできない状況になりかねません。

川上さんによると、若い仲間で集まっても、経営の話ができないのが現状だといいます。作業はできても、経営を知らないのです。

>> 川上｜経営を知らないんだよ。経営の話ができないんだよ。若い仲間で集まっても。

この点について青沼さんは、既存の牧場で作業している人こそ、目の前の牧場を教材にシミュレーションしやすいはずだと指摘します。

>> 青沼晃｜もう目の前にある牧場をシミュレーションすればいいだけなんで。本人にその気があれば、むしろしやすい環境なんじゃないんでしょうかね。

問題は、本人が「やばい」と感じて勉強しようとするかどうか。川上さんも、危機感がなければなかなか動けないと感じています。逆に、後継者がその姿勢を見せれば、親父さんも経営を渡してくれるかもしれない、と青沼さんは言います。

>> 青沼晃｜そういう姿勢を見せたら、もうそういうつもりがあるならって言って渡してくれるかもしれないし。

## これから入る人が「頼れる」業界にするために

川上さんは、青沼さんのように未経験から第三者継承を狙う人が、スムーズに業界に入れるようにしたいと考えています。

>> 川上｜そういう人たちがスムーズにこう入れるようにする業界にしたいんだよね。

青沼さんは、それは今の酪農家や従業員が担うべき課題だと応じます。次の担い手を育て、手が入りやすい環境を作る。それを一人ひとりが自分の立場で考えていく必要がある、というわけです。

>> 青沼晃｜もっともっと、次の担い手を育てるとか、手が入りやすい環境を作っていくだとか、一人一人がそれぞれの立場で、もっと考えれたら。

青沼さんによると、そうした取り組みが進んでいるのは北海道の事例です。酪農で経済が回っているだけに、力の入り方も違うといいます。一方で島根県や富山県のような産地では、担当の人がいないことも珍しくありません。

>> 川上｜自分でやるしかないんだもん、だって。

青沼さんが富山で酪農家と交流して感じたのは、次の人のことを考えている酪農家が本当に少ないこと。考えていても、せいぜい自分の牧場の後継者どまりだといいます。

>> 青沼晃｜やっぱ次の人のことを考えてる酪農家ってほんと少ない。

だからこそ、地域の酪農をどうしていくかを考える必要がある、と青沼さんは強調します。ただ、これから第三者継承を目指す人に「地域のことも考えなきゃいけない」と教えなければならない現状を、川上さんはきついとも感じています。

それでも青沼さんの姿勢は一貫していました。まず自分たちが一生懸命やる姿を見せる。その雰囲気が伝われば、向こうも頑張ってくれると信じてやるしかない、というのです。

>> 青沼晃｜信じてやってる。それしかないと思う。

## どんな人なら支えられる？青沼さんの本音

これから業界を担う世代の中間に立つ2人。100人が来ても全員を助けるのは無理な中で、青沼さんはどんな人なら支えられると考えているのでしょうか。

>> 青沼晃｜俺はその本人に動く意思がある人なら。ってかそういう人にしか無理だと思うし。

青沼さんの見極め方は具体的です。まずアドバイスをして、「好きな規模の牧場を自分でエクセルでも作ってみたら」と伝える。それで実際に動いて、作ったものを見せに来られるかどうかを見るといいます。

>> 青沼晃｜動いて、ちょっと作ってみたんですけど、自分なりに。見せに来れる人、そういうことを積み重ねていける人じゃないと、多分支えられないと思う。

青沼さんは、そうやって自分で動けない人は、そもそも経営者にはなれないと考えています。経営者は、いつまでにどうしたい、どの課題をいつ解決したいと常に考えているものだからです。

経営者である以上、いつまでにどうしたいとか、いつまでに解決したいとか、そういうのは常に考えてるわけじゃないですか。

たとえ1か月かかっても、「触りの部分しかできなかったけど、この方向性で合っているか見てもらえますか」と持ってくる人なら面白い、と青沼さんは言います。年数ではなく、行動できるかどうかを見ているのです。

実際、川上さんのところには、FacebookやFacebookを見て「牧場が作りたい」と初対面で電話してくる高校生がいます。青沼さんのところにも、漫画を見て酪農家になりたいと電話してきた小学3年生がいたそうです。

>> 青沼晃｜漫画を見て酪農家になりたいと思って。牧場が近くにあるのを知って電話させてもらいました。とりあえず電話した子がいて。

>> 川上｜20何歳で酪農経験が10年以上ありますっていう人より、そうやって来てくれた人の方が可能性があると思うから。

ただ2人が案じるのは、そうやって行動できる子ほど、今の厳しい業界で振るい落とされてしまうかもしれないことでした。

## 「絶対失敗できない」2人が背負う覚悟と、動いた成果

川上さんは、今の酪農がトップ集団と辞めていく人たちに二極化していると見ています。第三者が入るなら、そのトップ集団についていくくらいのことをしないと生き残れないといいます。

これに対し青沼さんは、二極化の中身は「当たり前のことを当たり前にできているかどうか」だと言います。

>> 青沼晃｜手元にあるお金の中で餌を買ってきて、自分たちの生活資金も捻出してっていうのをやれるかどうかだけ。

難しく考えず、当たり前のことをやる。そのためのサポートはしていきたい、と青沼さんは話します。実際、富山では前年の秋にもう1軒、第三者継承が成立しました。この年齢での成立は、富山の件数から言えば快挙だといいます。

その成立には、青沼さん自身が深く関わっていました。10年ほど前から話はあったのに、ずっと進んでいなかった案件です。前にやっていた人が高齢で「もうやめさせてくれ」となり、青沼さんもしびれを切らして動きました。

>> 青沼晃｜その肩書きを利用して。会長を今やらせてもらってるんですけど、富山県。それの名刺持ってあちこち行って。

川上さんも島根で、行政に動いてもらわないと進まない現状を感じています。そのために会議や発表、配信を続けているのですが、本音では2人とも穏やかに暮らしたいだけだといいます。

>> 川上｜本当は僕らも普通に牛舎で牛飼っときたいが。穏やかに暮らしたいんだよ。

それでも動く理由を、青沼さんは牛への責任と結びつけます。牧場を辞めても牛群を残したい、それが命に対する責任だ、というのです。

>> 青沼晃｜その牛群をちゃんと残していってあげたい。それが牛に対する命に対する責任かなって俺個人は思っていて。

一方で、青沼さんは明るい面もあると話します。この10年で、府県でも非農家からの新規参入者は確実に増えているというのです。

青沼さん自身、取材を受けたり農林水産省のヒアリングに呼ばれたりする中で、参入した側の要望を伝える機会が出てきました。そして、それが実際に制度改善につながっているといいます。

>> 青沼晃｜牛舎というハード面を買うのに、12年で返さないといけないっていうのはおかしいだろうって。

以前は5年据え置きの12年、実質最短7年で返す資金しかありませんでした。牛舎を買うのにこれはマッチしないと訴え続けた結果、償還期間が15年に延びたり、特例枠ができたりと、制度が変わってきたそうです。

新規参入者の声が動かした融資制度

BEFORE

5年据え置きの12年、実質最短7年で返す資金しかなく、牛舎を買うには短すぎた

↓

AFTER

償還期間が15年に延び、特例枠もでき、2軒目3軒目がやりやすくなった

だからこそ、青沼さんは「絶対に失敗できない」と言います。失敗すれば、上の対応が硬くなり、次の人がやりにくくなってしまうからです。

失敗したら次の人にもっと硬くなっちゃうとか。意地でももう成功しないといけないなって。

## 師匠はいない。「真似してほしいけど、真似できない」酪農の本質

続いて青沼さんは、次の世代に向けたメッセージを語りました。まず、絶対に悲観しないでほしい、というのです。

>> 青沼晃｜次の世代の人も絶対悲観しないでください。うちらもこうして頑張ってるんで、一緒に頑張ろう。

青沼さんが繰り返し伝えたのは、恐れずに人を頼ってほしいということでした。相手が忙しそうかどうかは無視していい、と言い切ります。

>> 青沼晃｜相手が忙しそうとかそんなん無視していいから。自分がやりたい酪農とか夢をつかむために、もっとがむしゃらになってほしいな。

川上さんも、経営者になればどのみちそういう行動が必要になると言います。まだ何も背負っていない今のうちにできないなら、経営者になってからでは無理だ、というわけです。

>> 川上｜何もまだ背負ってないし。もうそんな怖くないですから。他の農家さんも怖い人いないから。

話は、取材でよく聞かれる「師匠はいるか」という質問に及びました。2人とも、この問いには答えられないと言います。

>> 川上｜あの人のいいとこもあるし、この人もいいとこもあるしって思って、真似しようってやってきたから、本当オリジナルで自分でやってることがね。

いろんな人の良いところを真似してきた結果、自分のやり方はオリジナルになった。だから「真似してほしいけど、真似しちゃいけない」という不思議な関係になるのです。

その理由は、酪農の多様性にあります。状況が変われば同じやり方は通用しない。だからこそ、これが正解だと思ってほしくない、と川上さんは話します。

状況変わったら真似できないのもわかってるから。それが酪農なんですよね。

## 搾乳一人で3時間。過重労働のリアルな1日

番組の後半では、リスナーからの質問に答える形で、2人の1日のスケジュールが語られました。まず青沼さんの1日です。

青沼さんは5時前後に起き、餌をやってから6時〜6時半に搾乳を開始。今は一人で搾乳しており、40頭で2時間半、45頭を絞っていた頃は3時間かかっていたといいます。

その後も育成牛などの餌やりが続き、朝の作業が終わるのは10時か11時。午前中いっぱいかかります。午後は役員の仕事や雑務をこなすうちに夕方になり、16時頃から再び餌やりと搾乳。夜の搾乳が終わるのは、3時間かかれば21時になります。

>> 青沼晃｜もう明らかに過重労働。

財布の状況だけ見れば人を入れられるのに入れないのには理由がありました。青沼さんは、富山県の酪農家が30軒しか残っていない状況で、将来は県内の牧場を増やしたいと考えています。だから、ただの従業員ではなく、いずれ牧場を持ちたいと思っている人を入れたいのです。

>> 青沼晃｜従業員でありたい人じゃなくて、富山県でできれば牧場を持ちたいって、漠然とでも思ってる人を入れたいと。

一方の川上さんの1日は、青沼さんが「理想的」と羨むものでした。4時半に起きて餌やりと飼槽掃除をこなし、5時半頃から搾乳を開始。40頭を1時間ほどで絞り終えます。

その後は飼槽掃除や育成の配合、PMRの給餌などをこなし、9時からは会議や教育ファーム、種付けといった雑務。12時から15時までは休憩で、昼寝もするし夕飯の準備や買い物もするといいます。

>> 青沼晃｜いいなぁ。

川上さんは、今は親父さんが糞出しや堆肥の配達をやってくれていますが、いなくなっても昼間の空いた時間に自分が動ける体制に変えているといいます。ただ、早く経営を渡してほしい気持ちと、長く働いてほしい気持ちの両方があり、難しいところだと話しました。

>> 川上｜普通の話はできるけど、経営の話はしたくないね、もう。

## 諦めずに続けてほしい。2人からの最後のメッセージ

配信の終盤は通信トラブルで青沼さんが何度も退出してしまいましたが、最後にしっかりと締めのメッセージが語られました。

>> 青沼晃｜諦めずに続けてください。取り組んでください。それさえあればいいっか。実ると思います。夢叶えていくんでね。

川上さんが最後に強く勧めたのは、TwitterなどのSNSを有効に使うことでした。自分が就農を目指していた頃には無かったツールだといいます。

>> 川上｜もう僕欲しかったもん。だって自分がやりたかった時にこんなのがあったらもうすぐにでも、もうどこにでも行くつもりだが。

最後に川上さんは、この配信が本業に支障が出ない程度に、継続して続けていければと締めくくりました。

## まとめ

非農家から酪農家になった川上さんと青沼さんの対話からは、第三者継承のリアルな厳しさと、それでも次の世代のために動き続ける2人の覚悟が伝わってきました。安易な成功例ではなく、行動できるかどうかがすべてだというメッセージが一貫しています。

-- 青沼さんは24頭のつなぎ牛舎を継承し、お金をかけずに省力化する道としてフリーバーンを選んだ
-- 後継者がいても経営を知らないまま親が倒れると経営が傾く、という業界の危うさを2人は問題視している
-- 青沼さんが支えられると考えるのは「自分で動いて、作ったものを見せに来られる人」だけ
-- 新規参入者の声が農水省に届き、融資の償還期間が12年から15年に延びるなど制度改善が進んでいる
-- 状況が変われば同じやり方は通用しないため「真似してほしいけれど真似できない」のが酪農の本質
