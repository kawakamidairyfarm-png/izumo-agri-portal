## 作業前の休憩と、島根早生の話から始まった

この日は「作庭」と呼ばれる作業の予定で、川上さんは前日の疲れで首を痛めながらの収録です。牛を動かさないといけないという話から、休憩がてらの雑談が始まります。

そんな中で研修生が切り出したのが、川上さんが見せた資料の話でした。「島根早生」のホームページや、文字ばかりの資料をちらっと見たことがきっかけで、酪農と地域の関係について考えたと言います。

## 酪農は県と「運命共同体」だと気づいた

研修生はもともと酪農以外の仕事をしていたそうです。その頃は、県や市町村の動きが自分の仕事とは切り離されていて、「関与していない」感覚だったと振り返ります。

>> 研修生｜俺らはそこに住んどるけど、別に（県や市の流れが自分の仕事と）イコールじゃなかった。

ところが酪農は違う、と研修生は言います。国や市町村のバックアップありきで成り立っている以上、県の方向性と切り離せないと気づいたそうです。

!! 研修生｜酪農ってね、ゴリゴリに県と運命共同体やから

川上さんも、人口が減る予測がついているのに「牛乳を搾れ、和牛を作れ」と言われる違和感を口にします。方向性がずれていると感じつつも、拒絶するのではなく理解して利用する姿勢が大事だと2人は話します。

>> 研修生｜（県の方向性は）拒絶じゃなくて、まあうまいこと利用してやろうじゃないですけど、まずはそっちの方向性をやっぱりちゃんと理解してないと

ただ、他の業種にいた頃はこうした感覚が全くなかったと研修生は言います。飲食店の個人事業主なら、県の意向より立地や家賃で決めるのが普通だからです。

## 他の業種なら、県の意向は「ほぼ無視」でよかった

研修生は、多くの業種では県の方向性を気にしなくても数字が変わらないと指摘します。だからこそ酪農は特殊で、自分がいる場所の動きを知らないままの人が多いのではないか、と自分自身を例に振り返ります。

>> 研修生｜自分の県自体の動きは正直あんまり追う必要性ないみたいに感じてる人も、僕とかやったらそうなっちゃってたかもなと思った

一方で川上さんは、行政側にも問題があると感じています。国が新しい施策を打ち出しても、担当者の頭にイメージが浮かんでいないと、こちらがやりたいと言っても動けないのだと言います。

川上さんは、担当者に断られて上の人に直接聞くと「進めてください」と言われ、それがまた下に落ちてくる、という噛み合わなさを語ります。

## 「ブーメランを避ければいい」派と、川上さんのズレ

自分に不利益が返ってくるとわかっていても、研修生いわく多くの人は「そのブーメランを避ければいい」と考えるそうです。ここで2人の価値観の違いがはっきり出ます。

>> 研修生｜自分に返ってくるって言いながら、そのブーメラン避けたらよくね？もう逆にみたいな感覚あると結構回避率上がるでみたいな。

!! 研修生｜酪農っていう目でニュースを見ようとしてる人はやっぱ少ないと思う。それしてると、いい意味で変態になれてる

## いつ聞いてもらえる？「ミルク御殿」を建てるまで問題

川上さんは、自分がやりたいことを可視化して伝えても、相手が興味を持って聞いてくれるのはいつなのか、という悩みを口にします。研修生の答えはシビアでした。

>> 研修生｜それはもう成功して、ミルク御殿を建てまして、「なんでそんな成功したんですか？」って聞かれてからスタートですよ。

つまり、成功して周りから聞かれる立場になって初めて話を聞いてもらえる、というわけです。川上さんは「きっつ」と苦笑します。

ここから研修生の主張の核心が出てきます。見えないと動けない人がほとんどで、現実にないものを未来のビジョンとして持って動ける人は、酪農に限らず人間全体でもごくわずかだと言うのです。

>> 研修生｜未来のビジョンを持ってやってる人自体が、人間の中でも比率すごい少ないと思います。

## 整体で「ダンクがしたい」と書いた川上さん

川上さんは、体のメンテナンスで通う整体で回数券を買った時のエピソードを語ります。姿勢が良くなったら何がしたいかを問診票に書く欄があり、そこに本気で「バスケでダンクがしたい」と書いたそうです。

>> 川上｜バスケでダンクがしたいって書いたら大爆笑された。マジだもん。

研修生いわく、多くの人はここで「健康に歩きたい」のような無難な答えを書くのだそうです。書けと言われても、8割から9割の人は明確なビジョンを持っていないという見立てです。

>> 研修生｜書いたとしても、書かんかったとしても、8割9割はそうだと思います。

川上さんは24回通い終えて写真を見せ、「ダンクできますかね？」と本気で聞いて再び笑われたと言います。そしてまた24回分を買い、同じ質問に「ダンクがしたい」と答えたそうです。この極端さが、後の「ビジョンを持つ側の少数派」という話とつながっていきます。

## 「スーパーで何を買いに来たか言えるか」問題

研修生は、ビジョンの話をもっと身近な例に落とし込みます。それが「スーパーで何を買いに来たのか言えるか」という問いです。買い物メモを促すアナウンスにも、来てしまった客に言っても意味がないと引っかかります。

>> 研修生｜スーパー何しに来たん？何買いに来たん？って言われた時に「これです」って言える人（が少ない）

さらに研修生は、リストを持っている率よりも、書いた通りに買った人の率のほうがもっと低いと指摘します。「お買い得だから」「思い出したから」で買ったものはカウントしない、という厳しい基準です。

川上さんは、自分は買い物でそれしか買わず、ルートも決まっていて「今日は何しようかな」という発想がないと答えます。研修生は、それができている人はむちゃくちゃ少ないと返します。

>> 研修生｜どこのスーパーだろうと、自分の買いたいものだけ買おうって思うことをやれてる人ってむちゃくちゃ少ない。

## 「スーパーでランダムを楽しむ」からシンプルでいたい

川上さんが以前「（仕事に）もっとランダム性が欲しい」と言っていたことに触れ、研修生はその価値観のズレを説明します。多くの人はスーパーで衝動買いをして、そこでランダムを楽しんでいるのだと言うのです。

>> 研修生｜みんながスーパーでランダムを楽しんでるから、（仕事の）ランダム性ってそんなに価値あるん？って思う

研修生は、それをギャンブルに近いと考えています。安いと思って買っては太り、高いダイエット食品を買っては効果がない、を繰り返す。日常でそうやってランダムを楽しんでいるから、仕事ではシンプルで何も考えたくないのではないか、という見立てです。

>> 研修生｜普段の仕事はランダムをこっちで楽しんでるから、こっちはシンプルでいたいわけですよ。何も考えたくないわけですよ。

## 冷蔵庫と賞味期限に見える「在庫の必要性」

話は在庫管理の感覚に移ります。研修生は、冷蔵庫の残り物でパパッと料理を作ることがすごいとされる風潮に疑問を投げかけます。

>> 研修生｜冷蔵庫の残り物で主婦がパパッと料理を作ることがすごいことみたいになってるけど、ほんまに賢い人は残んないんじゃないか

余ったもので作れるということは、そもそも過剰に持ってきているということで、効率が悪い、という考え方です。川上さんは「在庫の必要性が全く考えられない」と驚きます。

>> 研修生｜余らしてる時点で過剰に持ってきてるんですよね、ってことは効率が悪い話で。

研修生は、賞味期限が切れても「使ったらいい」と考えたり、大きな冷蔵庫を欲しがって中身を余らせたりする例を挙げます。自分が運べないのに、どんどん抱え込むほうへ進んでしまう姿を「ビジョンを見ていない」と表現します。

## 「行列に信頼を感じる」多数派と、逆張りの少数派

研修生は、日本人が行列に信頼性を感じる傾向を例に、多数派と自分たちの違いを語ります。列ができているから並ぶ、人がいないから美味しくない、と判断する感覚です。

研修生も川上さんも、ラーメンなら「安く自分で作るか、カップ麺か」「行列に関係なく行ける店か」の二択で、中途半端に美味しくて並ぶ店には行かないと語ります。この考え方は多数派と完全に逆だと研修生は言います。

## 多数決社会で少数派はどう動くか

研修生は、イメージ戦略が通用するのは「何も考えていない人」がいるからだと言います。もし考える人ばかりの国なら、雰囲気ではなく「何ができるか」で判断されるはずだと語ります。

>> 研修生｜あなたに何ができるかや。「なんとなくいい感じやから」は、自分で考える人には通用しない

だからこそ、少数派の考え方は世界的に見ても比率としては少ないと研修生は認めます。ただ、それでも人類にはそのくらいの成分でちょうどいいのかもしれない、と冷静に付け加えます。

そのうえで研修生は、多数決や暴動といった従来のやり方が窮屈になってきたと指摘します。声を上げるだけでは足りず、その後に何をするかが大事だと言います。

>> 研修生｜声上げた後に何をやるかで全然（変わる）。今って声上げて、暴動でっていうアクションしか起こせてなくて

## 歩み寄るために「尖る」しかない

川上さんは、こうした価値観の違いから、今の自分が「やりにくさ」を感じていると打ち明けます。研修生は、動く側が歩み寄るだけでなく、受け取る側が体の向きを変えてくれないと成立しないと返します。

>> 研修生｜動く側が寄ることも大事ですけど、受け取る側が（体の向きを）向けてくれないと

研修生はこれを、いくらメールを送ってもブロックやミュートされている状態にたとえます。だから、まずブロックを解除させ、メールをちゃんと見てもらう行為が必要だと考えています。

そのために研修生が提案するのは、無理に歩み寄って良さを消すのではなく、むしろ尖ることです。ただし尖りすぎると下がれなくなる、そのバランスが難しいと言います。

!! 研修生｜歩み寄りたいからこそ、あの、尖るというか、もっとそっちに

## 「好き」を数字で整理して伝え合う教育

>> 研修生｜買い物リスト持ってない人に買い物リストを作らすというよりも、もっと整理させる。整理させてお互い伝え合う。

>> 研修生｜何歳の時にこういう状況になったっていうデータをカテゴリー分けにして、統計とデータで数字取って

内閣支持率のような数字ではなく、もう一段階上のレベルの数字を出し、そういう整理の仕方を教育していけばいい、というのが研修生の考えです。すぐに正解ではなくても、その教育を始めておくことに意味があると語ります。

## 天才の動きは「オートのガード」だから教えにくい

>> 研修生｜完全に一緒になったらほんまに価値はなくなるんで、完全に一緒になる必要性もない

研修生は、新人には「知らない」「わからない」という武器があると言います。ブルーブックを見てわからないこと自体が価値なのに、それを「今のやり方なんですか」という考えていない質問に変えてしまう、と指摘します。

かっこよくなりたい、モテたいと思った時点でもう無理だ、という話にも広がります。全くリスクを負わない状態で「何をしてみたんですけど」と聞いてくる人には、才能がないと研修生はばっさり言い切ります。

## 「YOUがやっちゃったよ」責任のなすりつけ

研修生は、考えないまま人に頼る人ほど、うまくいかないと責任をなすりつけてくると指摘します。国の動きの遅さや、有権者の信頼できなさも、同じ構図だと言います。

>> 研修生｜言われた通りにやったら「川上さんに言われたんですけど違うかったっすよ」ってなる。だからバカなんですよ。

研修生は、こうした人にはそもそも答えを言う必要がないと考えています。答えを渡すのではなく、自分で考えさせ、やらせて、ミスさせることが大事だと語ります。

>> 研修生｜こういう人たちは、ほんま答え多分いらんと思う。だから考えさせなあかんし、やらして、ミスさせる

川上さんも、これまで研修生に自分で考えるようやらせてきたと応じます。ただ研修生は、そこにも冷静な但し書きを付けます。

## 「ホームだから勝てる」だけかもしれない

研修生は、川上さんの牧場でできていることも、その環境あってのものかもしれないと言います。川上さんという存在があり、このエリアとこの条件だからこそ、能力を出せているという見方です。

>> 研修生｜川上さんっていうのがおるから、その能力でやらせてもらえてる。このエリアでこの条件だから、その能力が出せた

それを、野球のホームゲームにたとえます。自分は3打席ノーヒットでも、チームはホームで勝っている。そうなると、数字上は何もしていなくても「できた」と思えてしまう、というのです。

>> 研修生｜自分は3打席0安打なのに、チームはホームで勝ってるんですよ。「勝ってるもん」ってなっちゃう

だからこそ、環境の力なのか本人の力なのかを見極めるのは難しい、と研修生は締めくくります。分析を一通り語り終えたところで、2人はこの日の作業へと戻っていきました。

## まとめ

川上牧場の休憩中に始まった雑談は、研修生による川上牧場と「大多数の人」の分析へと深まっていきました。買い物リストや行列、整体のダンク話といった身近な例を行き来しながら、ビジョンを持つ少数派と、その場しのぎで動く多数派という見立てが繰り返し語られた回です。

-- 酪農は県や市町村と「運命共同体」で、地域の方向性を理解して利用する姿勢が必要だと研修生は語る
-- 現実にないものをビジョンとして持って動ける人は、酪農に限らず人間全体でもごく少数だという見立て
-- 「スーパーで何を買いに来たか言えるか」「冷蔵庫を余らせるか」など、身近な例でその差が説明された
-- 天才の動きは無意識の「オートガード」なので、細分化して8割の人に伝わる言葉へ翻訳する必要がある
-- 環境（ホーム）の力か本人の力かは見極めが難しく、それでも自分の武器を確認し直すことが大事だと締めくくる
