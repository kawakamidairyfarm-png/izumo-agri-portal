# 新しい配信を足すときは、このフォルダにファイルを置くだけ

このフォルダ（`databank/inbox/`）に文字起こしのファイルを入れると、
GitHub が自動で取り込んで、サイト（酪農データバンク）に反映します。
パソコンに特別なソフトは要りません。GitHub のページ上でアップロードするだけです。

## 手順（GitHub のページ上で）

1. このフォルダを開いた状態で、右上の「Add file」→「Upload files」を押す
2. 文字起こしのファイル（.txt）をドラッグして入れる
3. 下の「Commit changes」を押す（緑のボタン。入力欄はそのままでよい）
4. 数分待つと、サイトに新しい回が出ます
   （進み具合は上の「Actions」タブに出ます。緑のチェックなら成功）

## ファイルの決まり

- 名前は **`20260907_タイトル.txt`** の形（日付8桁 ＋ 下線 ＋ タイトル）
  例: `20260907_乳房炎が減らないときに見直すこと.txt`
- 中身は文字起こしの本文（そのまま）
- 先頭に次のような行を書くと、その回のリンクも一緒に登録されます（書かなくてもよい）

```
note: https://note.com/kawakamifarm/n/xxxxxxxxxxxx
youtube: https://youtu.be/xxxxxxxxxxx
spotify: https://open.spotify.com/episode/xxxxxxxxxxxx

（ここから本文）
```

- ファイル名に日付やタイトルを入れられないときは、先頭にこう書いてもよい

```
日付: 2026-09-07
タイトル: 乳房炎が減らないときに見直すこと
```

取り込みが終わると、ファイルはこのフォルダから消えて `data/transcripts/` に移ります。
同じ日付・同じタイトルの回がすでにあるときは、本文とリンクだけが足されます。

## note の記事は自動で入る

note に無料記事を公開すると、毎日 12 時ごろに自動で見に行って取り込みます。
このフォルダに置くのは、note に出していない回（音声だけの回など）だけで大丈夫です。

- 無料記事 → 本文が「全文」としてサイトに載ります
- 有料記事・メンバーシップ限定・Farmers Voices → 本文は載せず、「note の有料記事で読める」と案内だけ出します

すぐに反映したいときは、「Actions」タブ →「新しい配信を取り込む」→「Run workflow」を押してください。

## 有料の回の文字起こしを置いてしまったら

note が有料の回（`data/note_paid.json` に載っている回、または題名に Farmers Voices がある回）の
文字起こしは、公開されないフォルダ `data/transcripts_private/` に自動で避けられます。サイトには出ません。
